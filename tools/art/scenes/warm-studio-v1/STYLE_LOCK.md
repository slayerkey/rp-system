# Warm Studio Style Lock

This scene is approved as the reference direction for PackRat environmental marketplace heroes.

## Preserve
- Same warm studio environment: lamp left, plants, headphones right, dark background, rich wood desk.
- Large centered rear monitor.
- Large foreground hardware/product occupying most of the lower half.
- Minimal PackRat branding in the upper-right.
- No extra small marketing copy.

## Monitor typography
Match the approved Ultimate Bundle reference as closely as deterministic rendering permits:
- line 1: very large bold uppercase white
- line 2: very large bold uppercase orange
- subtitle: centered, smaller; `for` regular weight and the platform/product name bold
- text occupies most of the useful monitor width
- strong vertical spacing and clean center alignment
- dark near-black monitor background with restrained orange wave/dot decoration

For the approved reference the copy is exactly:
- `ULTIMATE`
- `BUNDLE`
- `for XENEON Edge`

The visual hierarchy is part of the approved style and should be reused for other products by changing copy, not by shrinking the typography or adding supporting paragraphs.
