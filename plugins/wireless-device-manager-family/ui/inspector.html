Lite focuses on one selected device. Pro expands the same workflow into a complete multi-device control center.

  • Dedicated device keys — keep multiple devices available without rebinding one Lite key.

  • Groups, alerts, and dashboards — organize devices and watch low-battery state across your setup.
Hardware honest

Battery and charging appear only when Windows or a supported device protocol exposes them. Supported USB receivers can work without Bluetooth. Control stays disabled per device when it cannot be done reliably.
