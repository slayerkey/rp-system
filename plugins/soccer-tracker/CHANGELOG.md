## v1.0.0.0 - 2026-07-30

- First release. Windows and macOS.
- Team Score: live score for the team you pick, refreshing on its own while the game is on. When
  there is no game, the same key counts down to the next one and shows the opponent.
- Standings: your team's rank, record, points and current run of form. Press the key to swap
  between the competition table and the division table.
- League Scoreboard: every match playing today in a competition you pick, live ones first.
  Press for the next match.
- A green frame flashes on the key when your team scores or the game starts.
- Set any key to open that game's page instead of refreshing.
- Keeps showing the last score it got when the connection drops, with an amber bar and the age of
  the data, so a stale number never passes for a live one.
