Steps

Steps run top to bottom. Drag is not needed, use the arrows to move one up or down.

A wait is worth putting after anything slow to open. It is the difference between typing into the program you meant and typing into whatever was in front when it had not finished loading yet.

If a step goes wrong the routine stops there and the key tells you which one, rather than carrying on.

One press runs one sequence. Keystrokes are sent to whatever window has focus at that moment. On a Mac, allow Stream Deck under System Settings, Privacy and Security, Accessibility before key steps can work.
