# Changelog

## 1.1.0.0 - 2026-09-20

- Added Stream Deck+ dial support for scrolling through the full rolling clipboard history.
- Press the dial to paste the selected entry, with a readable preview and position shown on the touch strip.
- Tap the touch strip to jump back to the newest copied item while keeping the existing search, pin and named-key workflows.

## 1.0.0.0

- Added searchable 50-entry clipboard history that survives restart.
- Added pinned entries with key-hold pin and unpin controls.
- Added named recent and pinned keys.
- Added explicit plain-text paste.
- Added an interactive Property Inspector picker with key-hold match cycling.
- Kept settings and history isolated from Clipboard Manager Lite.
