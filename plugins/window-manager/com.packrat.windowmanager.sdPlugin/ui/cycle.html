Which windows should this key step through?

Each press brings the next window forward. Keep pressing and you work your way through all of them, then start again from the top.

Staying inside one program is the quicker way to move between two documents or two browser windows without everything else getting in the way.

The key face names the window you land on next, so you know where a press takes you before you make it.

On a Mac, allow Stream Deck under System Settings, Privacy and Security, Accessibility before this can see your windows.
