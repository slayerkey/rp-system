Where should this key put the window?

A press moves whatever window you are working in. Give one key the left half and another the right half and you can set up a side by side view in two presses.

Choosing a screen sends the window across to it as well as positioning it. Leave it set to stay put and the window is arranged on whichever screen it is already on.

The key face draws the shape it makes, so a row of these is easy to tell apart at a glance.

Some windows cannot be moved. On Windows that means anything run as administrator, unless Stream Deck is running as administrator too. On a Mac, allow Stream Deck under System Settings, Privacy and Security, Accessibility.
