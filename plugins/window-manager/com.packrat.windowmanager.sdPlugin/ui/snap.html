Snap Window

Put the active window exactly where you want it in one press.

Position

Use separate keys for left, right, center, or full screen to build a fast window-control row.

Choosing a screen moves the window there first. Leave it unset to arrange the window on its current display.

Some windows cannot be moved. On Windows, elevated apps require Stream Deck to run with matching privileges. On macOS, allow Stream Deck under Privacy & Security → Accessibility.
