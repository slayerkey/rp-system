Monitor Manager Pro

Control the Windows display layer and supported monitor hardware from one Stream Deck plugin.

Monitor

Capability scan pending.

Value

Press once to use this preset. Press the same key again to restore the value that was active before it.

Monitor Power

This sends a DDC/CI monitor power command. It does not shut down Windows or physically cut AC power.

Input Source

Only input values advertised by this monitor are offered. Input switching is not auto-undone because switching away can disconnect the control path itself.

Refresh Rate

60 Hz and above are prioritized; the current rate stays visible even if it is lower. Press the same configured key again to restore the previous mode.

Resolution / Hz

Highest resolution / highest refresh is first, then 1920×1080 modes, then the remaining resolutions. Only Windows-reported modes are offered.

Windows HDR

The key shows HDR ON, HDR OFF, HDR N/A, or HDR ? from the live Windows display path.

Display Mode

Extend gives each display its own desktop. Duplicate mirrors the same desktop. Pressing the same topology key again restores the previous topology when Windows still reports it.

Orientation

Press the same configured orientation key again to restore the previous display mode.

Monitor Profile

Save captures the setup you have right now: Windows display topology, resolution, refresh rate, orientation, primary display, HDR, brightness, contrast, supported monitor volume, and supported input source. Monitor power is intentionally not saved.

Apply restores that named snapshot and reports COMPLETE, PARTIAL or FAILED. If you lower brightness before pressing Save, that lower brightness is the value the profile stores.

Hardware honest

DDC/CI varies by monitor. Pro uses advertised capabilities and safe allowlisted VCP controls. Unknown support is not treated as supported.
