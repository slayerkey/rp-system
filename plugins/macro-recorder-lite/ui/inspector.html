Local by design

Macro contents are never uploaded to PackRat. Do not deliberately record passwords. Windows secure-desktop input is outside the normal recording desktop, but ordinary app password fields cannot be identified reliably.

Lite stores an assigned macro in that Stream Deck action's local settings. If you export or share a Stream Deck profile containing the action, those settings can be included in the exported profile.

Pro stores the reusable Macro Library in your local AppData. Macro contents leave the library only when you explicitly export a PackRat macro file.
