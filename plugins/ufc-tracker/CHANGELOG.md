## v1.0.0.0 - 2026-07-30

- First release. Windows and macOS.
- Next Event: the next card, its main event, and a countdown once it is close.
- Fight Card: every bout on the card, one at a time, main event first. Once a bout is settled the
  key shows who won.
- Set the event key to open the card's page instead of refreshing.
- Keeps showing the last card it got when the connection drops, with an amber bar so nothing stale
  passes for current.
