# DaVinci Resolve Pro

Grading and editing on real labeled keys. Nothing to configure.

## Pick your file

Import the one file that matches your deck and your computer. The others can stay
in the folder or be deleted.

|---|---|---|
| Stream Deck MK.2 (15 keys) | `DaVinci Resolve Pro.streamDeckProfile` | `DaVinci Resolve Pro (Mac).streamDeckProfile` |

## Install

1. Close DaVinci Resolve if it is open.
2. Double-click your `.streamDeckProfile` file. The Stream Deck app imports it and
   asks which device to put it on.
3. Open Resolve. The profile switches in on its own when Resolve has focus.

If double-clicking does nothing, open the Stream Deck app, click the gear icon,
choose **Profiles**, then the **...** menu, then **Import**, and pick the file.

## Read this before using the Color page

Resolve's printer light commands only respond while **printer lights mode is on**.
Press the **Printer Lights** key once to turn it on. That key is a switch: it shows
a lit bulb while the mode is active, so you can always see whether the color
controls are live. Press it again to turn the mode off.

Until you do that, the master, red, green and blue keys and dials will appear to do
nothing. This is how Resolve behaves, not a fault in the profile.

## Using it

Five pages, reached from the folder keys on the front page.

**Color** holds printer lights for master, red, green and blue, plus serial,
parallel and layer nodes, bypass node, bypass all and node stepping.
**Grade** holds grade memories with save and recall, grab the grade from the
previous clip, add version and next version.
**Edit** holds blade, select, split, ripple delete, snap, trim, zoom fit and markers.
**Assembly** holds insert, overwrite, replace, place on top, append, transitions
and retime.

On Stream Deck +, each of the four dials drives one printer light channel on the
Color page, and the Edit page puts timeline scrub, zoom and undo on the same dials.
On MK.2 and XL the identical printer light commands sit on labeled keys, so the
color control surface is not limited to the Plus.

## Zero setup

Every key sends a shortcut that DaVinci Resolve already ships with, on its default
keymap. There is no keyboard preset to import and nothing to remap. If you have
customized your own Resolve shortcuts, reset the ones you changed back to default
and the keys will match again.
