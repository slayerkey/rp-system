# Valorant — Stream Deck MK.2 profile

**Price: $8.99** (only competitor: $5; this ships more pages and a cleaner input-safety story)

Three pages: a match-companion home (comms, clips, votes, intel), a **Game page** tapping
Valorant's default keybinds, and a crosshair-codes folder.

## Input-safety position (updated 2026-07-16)
v1 sent zero input to the game. Owner's decision + market precedent (the existing marketplace
Valorant profile ships equipment/ability/interface hotkeys) moved this to the standard model:
**every game key sends a single tap of Valorant's own default keybind — one press, one action.**
No macros, no sequences, no automation, which is what Riot's anti-cheat policy actually targets.
Marketing copy says "one press, one action, no macros" and never claims Riot endorsement.
