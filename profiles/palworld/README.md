## Buyer setup
1. Install the free **Better Hotkeys & Mouse** plugin (com.packrat.betterhotkeys) — Stream Deck
   prompts for it on import.
2. Sort Inv: open the button in the Stream Deck app once and set the click position to where
   Palworld's inventory Sort button sits on your screen (stored as a screen percentage, so it
   survives resolution changes).
3. Keybinds assume Palworld defaults (Sprint=Shift, Attack=LMB, Map=M, Inventory=Tab, Build=B,
   Throw Pal=Q). If you rebound keys in Palworld, mirror the change in the button.

## Research rationale
Community demand for auto-run is documented (Steam discussions, a retired Nexus auto-run mod);
sorting is a UI click with no keybind, hence the click-at-spot button (profiles/RESEARCH.md §5).
Cut: Roll (bare Ctrl tap is useless from a deck), weapon-slot keys (1-4 are already under the
hand), crouch, and anything a keyboard hand reaches faster than the deck.
