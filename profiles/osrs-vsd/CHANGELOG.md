## v1.0.0 - 2026-08-17

- First release. All thirteen interface tabs on their own keys, on the game's own default function key layout.
- Grand Exchange prices, the DPS calculator, Wise Old Man, TempleOSRS and hiscores, one press each.
- The wiki, a full world map, the quest list, the world switcher and official news.
- Tabs and reference tools sit together on one screen, so there is no Guide folder to open first.
- Included for Virtual Stream Deck, on Windows and Mac. If you have rebound a tab, change that one key in the Stream Deck app to match.
