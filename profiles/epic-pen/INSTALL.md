# Epic Pen Profile

Every Epic Pen tool on a labeled key. Draw on your screen without hunting for the
floating toolbar.

## Pick your file

Import the one file that matches your deck. The others can stay in the folder or
be deleted.

| Your Stream Deck | File |
|---|---|
| Stream Deck / MK.2 (15 keys) | `Epic Pen Profile.streamDeckProfile` |
| Stream Deck XL (32 keys) | `Epic Pen Profile (XL).streamDeckProfile` |
| Stream Deck + (8 keys, 4 dials) | `Epic Pen Profile (Plus).streamDeckProfile` |
| Virtual Stream Deck | `Epic Pen Profile (VSD).streamDeckProfile` |

## Install

1. Install Epic Pen from epicpen.com if you do not have it yet.
2. Double-click your `.streamDeckProfile` file. The Stream Deck app imports it and
   asks which device to put it on.
3. Start Epic Pen. The keys work as soon as it is running.

If double-clicking does nothing, open the Stream Deck app, click the gear icon,
choose **Profiles**, then the **...** menu, then **Import**, and pick the file.

## Check your hotkeys first (takes 30 seconds)

Epic Pen lets you change every shortcut, so this profile is built on Epic Pen's
factory defaults. Open Epic Pen, go to **Settings > Hot keys**, and check yours
still look like this. If one is different, either set it back in Epic Pen or edit
that single key in the Stream Deck app.

| Key on your deck | Epic Pen shortcut |
|---|---|
| Draw | Ctrl+Shift+1 |
| Cursor | Ctrl+Shift+2 |
| Pen | Ctrl+Shift+3 |
| Highlight | Ctrl+Shift+4 |
| Eraser | Ctrl+Shift+5 |
| Undo | Ctrl+Shift+6 |
| Clear | Ctrl+Shift+7 |
| Last Color | Ctrl+Shift+9 |
| Toolbar | Ctrl+Shift+0 |
| Screenshot | Ctrl+Shift+PrintScreen |
| Size + | Ctrl+Shift+] |
| Size - | Ctrl+Shift+[ |
| Colors 1 to 6 | Alt+Shift+1 to Alt+Shift+6 |

## About the color keys

The six color keys select **palette slots**, not fixed colors. Slot 1 fires
whatever color you have in slot 1. Epic Pen ships them in this order out of the
box, which is what the key faces show:

| Key | Factory color |
|---|---|
| 1 | Cyan |
| 2 | Yellow |
| 3 | Pink |
| 4 | Black |
| 5 | Green |
| 6 | Red |

If you have picked your own quick colors the keys still fire the right slots, they
just will not match the colored faces. Set your palette back to the order above and
everything lines up again.

## Using it

The main page holds what you reach for constantly: pen, highlighter, eraser, clear,
undo, cursor, stroke size and screenshot. The **Colors** key opens the palette page.
**Draw** turns the ink overlay on and off. **Cursor** hands control back to whatever
is underneath so you can click again.

On Stream Deck XL and the Virtual Stream Deck everything sits on one page, with no
folder to open.

On Stream Deck +, the first dial changes stroke size as you turn it.

## Notes

There is no Redo key because Epic Pen has no redo shortcut.

Windows only.

## What Pro adds

Epic Pen Pro Profile expands this to four pages. A **Shapes** page adds line,
arrow, rectangle, ellipse and text, with pen and undo alongside so you can fix a
mistake without leaving the page. A **Boards** page adds whiteboard, blackboard
and fading ink for drawing over a clean background instead of your screen.
