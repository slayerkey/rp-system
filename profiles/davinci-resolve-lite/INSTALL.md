# DaVinci Resolve Lite

Playback, in and out points and markers on real labeled keys. Nothing to configure.

## Pick your file

Import the one file that matches your deck and your computer. The others can stay
in the folder or be deleted.

| Your Stream Deck | Windows | macOS |
|---|---|---|
| Stream Deck MK.2 (15 keys) | `DaVinci Resolve Lite.streamDeckProfile` | `DaVinci Resolve Lite (Mac).streamDeckProfile` |
| Stream Deck XL (32 keys) | `DaVinci Resolve Lite (XL).streamDeckProfile` | `DaVinci Resolve Lite (XL Mac).streamDeckProfile` |
| Stream Deck + | `DaVinci Resolve Lite (Plus).streamDeckProfile` | `DaVinci Resolve Lite (Plus Mac).streamDeckProfile` |

## Install

1. Close DaVinci Resolve if it is open.
2. Double-click your `.streamDeckProfile` file. The Stream Deck app imports it and
   asks which device to put it on.
3. Open Resolve. The profile switches in on its own when Resolve has focus.

If double-clicking does nothing, open the Stream Deck app, click the gear icon,
choose **Profiles**, then the **...** menu, then **Import**, and pick the file.

## Using it

One page on every device. MK.2 and XL have eleven Resolve keys: Select, Marker,
J reverse, K stop, L play, In, Out, Undo, Redo, Snap and Zoom Fit.

Stream Deck + has five Resolve keys: Select, Marker, Zoom Fit, In and Out. Its
single Scrub dial moves the timeline playhead one frame per detent. Two keys and
three dials stay unassigned.

Every variant also has one **Get Pro** key that opens the DaVinci Resolve Pro
listing. That makes twelve assigned keys on MK.2 and XL, and six on Plus.

## Zero setup

Every key sends a shortcut that DaVinci Resolve already ships with, on its default
keymap. There is no keyboard preset to import and nothing to remap. If you have
customized your own Resolve shortcuts, reset the ones you changed back to default
and the keys will match again.

## What Pro adds

DaVinci Resolve Pro expands the profile to five pages. Its Edit and Assembly pages
add blade, split, ripple delete, trim, insert, overwrite, replace, place on top,
append, transitions, retime and edit point stepping. Its Color and Grade pages add
printer lights for master, red, green and blue, node controls, grade memories and
versions. On Stream Deck +, the four Color-page dials map directly to the four
printer light channels, while the Edit-page dials carry timeline scrub, zoom, undo
and edit point stepping.
