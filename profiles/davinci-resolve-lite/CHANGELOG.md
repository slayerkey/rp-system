# DaVinci Resolve Lite changelog

## v1.1.0 - 2026-09-04

- Blade, Split and Ripple Delete, and the entire Assembly page (Insert, Overwrite, Replace, Place on Top, Append, Add Transition, Retime, Disable, Trim, previous and next edit point, frame stepping) have moved to DaVinci Resolve Pro. This is a deliberate change, not a mistake. Lite is now the playback and marking starter set for the Resolve edit page.
- MK.2 and XL keep Select, Marker, J K L transport, In, Out, Undo, Redo, Snap and Zoom Fit. Stream Deck + keeps Select, Marker, Zoom Fit, In and Out.
- The Stream Deck + build drops from four dials to one, timeline Scrub. The Zoom, Undo and Edit Point dials have moved to DaVinci Resolve Pro.
- New Get Pro key opens the DaVinci Resolve Pro listing straight from the deck.
- Using any of the keys or dials listed above? DaVinci Resolve Pro carries all of them, alongside its Color and Grade pages.

## v1.0.1 - 2026-08-23

- Added a DaVinci Resolve Pro shortcut and a clear guide to the extra Color and Grade controls included with Pro.

## v1.0.0 - 2026-08-11

- First release with Edit and Assembly pages for Stream Deck MK.2, XL and Plus on Windows and macOS.
