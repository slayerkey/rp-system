## v1.0.1 - 2026-08-31

- Added a setup guide to the download. The Mute, Deafen and capture keys press hotkeys in
  Discord and OBS, and nothing in the download said so, so those keys looked broken out of
  the box. The guide now covers both apps, including the Discord one that catches most
  people out: Fortnite runs as administrator for its anti-cheat, so Discord has to as well
  or it never hears the key.
- The listing now says up front which keys need Discord and OBS.
- No change to the profiles themselves. Every key was already sending the right keystroke.

## v1.0.0 - 2026-07-31

- First release. Three pages: comms and capture on the home screen, Battle Royale keybinds on the Game page, and stats, item shop, patch notes and map links on the Links page.
- Included for Stream Deck MK.2 and Stream Deck XL on Windows.
- Game keys match Fortnite's default Battle Royale bindings, so there is nothing to set up in game.
