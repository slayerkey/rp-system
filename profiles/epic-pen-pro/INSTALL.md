# Epic Pen Pro Profile

Every Epic Pen tool on a labeled key, including shapes, text, the boards and
fading ink.

## What needs Epic Pen Pro

Read this before you set up, so nothing surprises you.

| Keys | Requirement |
|---|---|
| Pen, Highlight, Eraser, Clear, Undo, Cursor, Draw, Toolbar, Size, Screenshot, the six Colors, Last Color | Work on any Epic Pen install |
| Line, Arrow, Rectangle, Ellipse, Text, Whiteboard, Blackboard, Fading Ink | Need Epic Pen Pro in the app itself |

The profile sends the same shortcut either way. Without Pro, Epic Pen simply does
not act on those eight.

## Install

1. Install Epic Pen from epicpen.com if you do not have it yet.
2. Double-click your `.streamDeckProfile` file. The Stream Deck app imports it and
   asks which device to put it on.
3. Start Epic Pen, or use the **Launch** key on the Boards page.

If double-clicking does nothing, open the Stream Deck app, click the gear icon,
choose **Profiles**, then the **...** menu, then **Import**, and pick the file.

The Launch key points at `C:\Program Files (x86)\Epic Pen\epicpen.exe`. If you
installed Epic Pen somewhere else, edit that one key and point it at your copy.

## About the color keys

The six color keys select **palette slots**, not fixed colors. Slot 1 fires
whatever color you have in slot 1. Epic Pen ships them in this order out of the
box, which is what the key faces show:

| Key | Factory color |
|---|---|
| 1 | Cyan |
| 2 | Yellow |
| 3 | Pink |
| 4 | Black |
| 5 | Green |
| 6 | Red |

If you have picked your own quick colors the keys still fire the right slots, they
just will not match the colored faces. Set your palette back to the order above and
everything lines up again.

## Page map

On Stream Deck MK.2 there are four pages:

- **Epic Pen**, the main page: pen, highlighter, eraser, clear, cursor, undo,
  stroke size, screenshot, fading ink, and the keys into the other three pages.
- **Colors**: the six quick colors and last color.
- **Shapes**: line, arrow, rectangle, ellipse and text, plus pen and undo so you
  can drop back to the pen and fix a mistake without leaving the page.
- **Boards**: whiteboard, blackboard, fading ink, toolbar, draw, screenshot and
  the Epic Pen launch key.

On Stream Deck XL and the Virtual Stream Deck all of it sits on one page, with no
folder to open.

On Stream Deck +, the first dial changes stroke size as you turn it.

## Notes

There is no Redo key because Epic Pen has no redo shortcut.
