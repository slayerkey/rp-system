## Page 2 — Pro (all Resolve defaults)
Insert **F9**, Overwrite **F10**, Replace **F11**, Place On Top **F12**, Append **Shift+F12**,
Add Transition **Ctrl+T**, Retime **Ctrl+R**, Disable Clip **D**, Trim mode **T**, Snap **N**,
Redo **Ctrl+Shift+Z**, Prev/Next Edit **Up/Down**. The F9-F12 three-point-editing family is the
workflow professional editors live on — validated against what the $30-35 packs sell.

## Page 3 — Captions & Colors (documented custom binds)
Resolve has NO default shortcuts for these, so the buttons send rare combos the buyer maps once
in DaVinci Resolve → Keyboard Customization:

| Button | Sends | Map to |
|---|---|---|
| Captions | Ctrl+Alt+Shift+L | Timeline → Create Subtitles from Audio |
| Normalize | Ctrl+Alt+Shift+N | Normalize Audio Levels |
| Orange…Pink (7) | Ctrl+Alt+Shift+1…7 | Set Clip Color → (color) |
| Clear Color | Ctrl+Alt+Shift+0 | Set Clip Color → Clear Color |

Five-minute one-time setup; the README table above ships with the listing.

## Buyer setup
Pages 1-2: none (default keymap). Page 3: the keyboard-customization mappings above. Resolve
must be focused when pressing keys.

## Research rationale
The 80% starter set came from cross-referencing shortcut cheat sheets against competitor packs
(profiles/RESEARCH.md §4). v2 added the researched pro layer: three-point editing (F9-F12),
retime/transition/disable, and the captions + clip-color workflow that owners of the big packs
actually use for timeline organization. Color page exists because "set clip color" has no
default binding in Resolve — same approach the premium packs take.
