# CS2: Packrat Stream Deck Profile

Buy menu, scoreboard, chat, reload and all five weapon slots, on CS2's own
default keybinds. Built for Virtual Stream Deck (Windows).

## Setup

Import the `.streamDeckProfile` file into the Stream Deck app. No in-game
keybind changes needed, every key sends a tap of a key CS2 already binds by
default.
