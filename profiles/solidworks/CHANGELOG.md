## v1.0.0 - 2026-08-01

- First release. Three pages: shortcut bar, search, zoom and the most-used views on the home screen, the full view cube on the Views page, and selection filters plus tools on the third.
- Included for Stream Deck MK.2 and Stream Deck XL on Windows.
- Every key is a SOLIDWORKS default shortcut, so there is nothing to set up before you start.
